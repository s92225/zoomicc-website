RSVP turned Instagram activity into a reusable content signal

A lightweight monitoring system that checks selected Instagram accounts, captures post metrics, and turns creative activity into a structured Notion database.

ClientRSVP
BusinessSocial content operations
WorkflowInstagram to Notion
System roleMonitoring database

The pain point

Instagram signals were visible, but not easy to review.

The team needed a repeatable way to watch several public handles without manually opening each profile, copying captions, saving media URLs, and rebuilding a reporting table.

01 / Accounts

Several handles

The workflow had to monitor slash.horse, dotai.hk, and rsvpcom as one cycle.

02 / Posts

Metrics scattered

Views, likes, comments, captions, post types, and media links lived inside Instagram.

03 / Review

No single board

The team needed one place to scan creative output and compare recent activity.

The Flow2 solution

Flow2 turned the monitoring run into a clean content database.

The automation cycles through a short list of Instagram handles, collects profile and media data, writes each post into Notion, and appends the image so reviewers can understand the creative without opening every post.

Track

Handles are managed centrally

The scenario starts from a controlled watchlist instead of ad hoc searches.

Capture

Post data is structured

Captions, media type, product type, date, permalink, and engagement fields map into Notion.

Review

Creative is visible

The image is attached to the record, so the database is useful as a review board.

The outcome

A simple watchlist became a lightweight content intelligence system.

The value is not just that posts are saved. RSVP now has a repeatable way to turn social content activity into a searchable review board with source links, creative previews, and engagement fields in one place.
