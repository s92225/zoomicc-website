Quotation workflow

PlayNest Events turned quote requests into a booking-ready operating flow

A quotation workflow that starts from a Google Sheets form response, prepares the quote document, creates the calendar hold, stores the contact, and gives the team one Notion task to follow.

ClientPlayNest Events
BusinessEvents and booking operations
WorkflowQuote request to calendar
System roleSales operations handoff

The pain point

One enquiry needed the same details in too many places.

A new quotation request was only the start. The team still had to save the customer, prepare a quote, block the activity date, and create a follow-up task before anyone could confidently move the job forward.

01 / Request

Form data was not enough

The Google Sheets row captured the enquiry, but it did not create the operational follow-up by itself.

02 / Quote

Documents took manual assembly

Each quote needed the same customer and event fields copied into a Word template.

03 / Handoff

Follow-up lived across tools

Contacts, calendar holds, quote links, and task notes needed to stay aligned after the first reply.

The Flow2 solution

Flow2 turned each quote response into a ready-to-action sales record.

The automation watches the quotation sheet, creates a Notion follow-up task, adds the customer to Google Contacts, generates the quote document from a template, places the activity into Google Calendar, and writes the working links back to Notion.

Capture

Quote request becomes a task

The first operational record is created as soon as the form response arrives.

Prepare

Quote document is generated

The Word template is filled with the booking details instead of rebuilt by hand.

Coordinate

Calendar and notes stay together

The event hold, quote link, and raw form details all return to the same Notion task.

The workflow keeps the quote, contact, calendar, and task moving together.

The outcome

The team can respond from one organised record instead of rebuilding the quote by hand.

The workflow does not replace the sales decision. It prepares the admin layer around the enquiry so staff can review the request, edit the quote, and follow up with the customer from a cleaner starting point.

01

Cleaner first response

The quote file and customer details are ready before the team starts replying.

02

Fewer missed handoffs

Calendar, contacts, document links, and Notion tasks stay connected.

03

Human review stays in place

Exception alerts keep the workflow from pretending every quote can be fully automatic.
